# 多模型划译助手：用户使用指南

## 1. 功能简介

本扩展通过 DeepSeek 与硅基流动的模型分流提供三类翻译功能：

- **划词翻译**：选择英语、日语或俄语单词/短语后，自动显示中文释义。
- **划段落翻译**：选择句子或段落后，以流式悬浮窗显示简体中文译文。
- **图片翻译**：可以右键翻译网页图片，也可以框选当前页面中的任意可见区域，适用于普通图片、Canvas、CSS 背景图等内容。

纯文本可优先使用 DeepSeek `deepseek-v4-flash`；未配置 DeepSeek 时回退到硅基流动。图片始终使用硅基流动，并可在 `Qwen/Qwen3.5-4B` 与 `Qwen/Qwen3.5-35B-A3B` 之间切换。

译文只在当前页面的悬浮窗中显示，不保存翻译历史。

## 2. 使用前准备

- Chrome 114 或更高版本。
- 图片翻译需要一个可用的硅基流动 API Key。
- 如需让划词/划段优先走 DeepSeek，还需一个 DeepSeek API Key；不配置时可继续使用硅基流动。
- 对应账户需要具备所选模型的调用权限及可用额度。

## 3. 安装扩展

本项目是免构建扩展，可以直接加载源码目录。

1. 打开 Chrome，在地址栏输入 `chrome://extensions/`。
2. 打开页面右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目中的 `chrome-extension` 文件夹。
5. 建议点击浏览器工具栏的拼图图标，将“多模型划译助手”固定到工具栏。
6. 如果安装前已经打开了网页，请刷新这些网页，使内容脚本生效。

每次修改扩展源码后，需要回到 `chrome://extensions/` 点击扩展卡片上的“重新加载”，并刷新测试网页和已经打开的设置页。点击工具栏图标时，扩展会检查当前页面并尝试补充加载内容脚本；若页面中仍是更新前已经失效的旧脚本，仍需手动刷新。

## 4. 配置供应商、模型与 API Key

首次安装时，扩展会自动打开设置页。也可以通过以下任一入口再次打开：

- 点击工具栏中的扩展图标，再点击“设置”；
- 在 `chrome://extensions/` 找到本扩展，依次点击“详细信息”与“扩展程序选项”。

设置页分为三部分：

1. **纯文本翻译供应商**：
   - `DeepSeek 优先`：配置了 DeepSeek Key 时，划词和划段使用 `deepseek-v4-flash`；没有 DeepSeek Key 时回退到硅基流动。
   - `仅使用硅基流动`：无论是否配置 DeepSeek，纯文本都使用所选 Qwen 模型。
2. **硅基流动**：选择 `Qwen/Qwen3.5-4B` 或 `Qwen/Qwen3.5-35B-A3B`，填写硅基流动 Key。模型选择会即时保存；图片始终使用这里选择的模型。
3. **DeepSeek**：填写 DeepSeek Key。模型固定为 `deepseek-v4-flash`。

每个供应商都可以单独“保存”或“保存并测试”。测试会发起一次很短的流式请求。设置页只显示已保存密钥的末四位，不会回显完整密钥；输入新值会替换旧值，“清除密钥”会删除对应供应商的本地保存值。

从 1.0 版升级时，原来的通用 `apiKey` 会自动迁移为硅基流动 Key。

## 5. 划词与划段落翻译

1. 在普通 `http://` 或 `https://` 网页中，用鼠标或键盘选择文本。
2. 当扩展检测到选中内容为英语、日语或俄语时，会自动发起翻译。
3. 页面选区附近会出现悬浮窗，译文通过流式响应逐步显示。
4. 点击“复制”可复制完整译文；点击“×”或按 `Esc` 可关闭窗口并取消尚未完成的请求。
5. 按住悬浮窗顶部带 `⠿` 标记的标题栏即可拖动位置；复制和关闭按钮不会触发拖动。窗口会始终限制在当前视口内，译文继续流式增长或浏览器窗口缩放时也不会跳回原位置。

点击扩展图标可以关闭或重新打开“自动划词翻译”。关闭后，图片翻译仍然可以使用。

悬浮窗底部会显示本次实际使用的供应商和模型。DeepSeek 已配置且选择“DeepSeek 优先”时，纯文本使用 DeepSeek；图片不会进入 DeepSeek。若 DeepSeek 已配置但请求失败，扩展不会静默重复调用硅基流动，以避免意外产生双重费用。

### 本地语言识别规则

为避免把中文内容意外发送到 API，扩展先在本地进行 Unicode 字符初筛：

- 日文假名与汉字占主要比例、且具有足够假名特征的文本按日语处理；
- 西里尔字母相对拉丁字母、汉字及其他文字占主要比例的文本按俄语处理；
- 文字字符均属于拉丁字母的文本按英语处理。

纯汉字的日语内容无法与中文可靠区分，因此不会自动发送。输入框、文本域和可编辑区域中的选择也会被有意忽略，避免把正在编辑的内容误传给翻译服务。单次选择上限为 20,000 个字符。

## 6. 图片翻译

图片翻译会截取并裁剪当前标签页的可见像素，只把裁剪后的区域发送给硅基流动所选 Qwen 模型，不会上传整页截图，也不会分流到 DeepSeek。扩展会在本地把图片等比例缩放到最长边不超过 2,048 像素、总像素不超过 320 万，并把 JPEG 控制在 3 MB 以内，减少 Base64 上传时间和内存占用。

### 方法一：右键网页图片

1. 在网页中的图片上点击右键。
2. 选择“翻译这张图片”。
3. 扩展截取该图片当前可见的区域，随后在图片附近流式显示识别与翻译结果。

如果图片只有一部分在屏幕中，扩展只会翻译可见部分。可以先滚动、缩放或单独打开图片，使文字更清晰、更完整。

### 方法二：框选图片区域

1. 点击浏览器工具栏中的扩展图标。
2. 点击“框选图片翻译”。
3. 在页面上按住鼠标左键并拖动，框住需要识别的区域。
4. 松开鼠标后，框选层会先隐藏，再进行本地截图和裁剪；完成截图后才会出现翻译悬浮窗。
5. 框选过程中按 `Esc` 可以取消。

框选模式适用于普通图片、CSS 背景图、Canvas、视频当前画面，以及嵌入页面中当前可见的内容。为了提高小字识别率，建议先放大网页，再紧贴文字区域框选。

悬浮窗会依次显示“截图完成”“图片已处理”“正在发送图片”“模型已响应”和“正在生成译文”等真实阶段，并在底部显示实际发送图片的像素尺寸与压缩后体积。持续的 SSE 心跳或空数据不会被视为有效译文；响应头、首段译文、输出停顿和总时长都有独立超时，失败时会显示具体原因，不会无限转圈。

## 7. API 配置与关闭思考

所有翻译和连接测试请求都由扩展后台脚本发送。

文本和图片分别使用内置的防提示词注入翻译提示词：模型只负责翻译，不应回答原文问题、执行原文/图片内指令或描述无关画面。扩展不启用工具调用；模型输出始终按纯文本显示。

## 8. 权限与隐私说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 在当前 Chrome 配置中保存两个供应商的 API Key、模型和分流设置 |
| `contextMenus` | 添加“翻译这张图片”右键菜单 |
| `activeTab` | 仅在用户点击扩展或图片右键菜单后，临时截取当前可见标签页 |
| `scripting` | 点击扩展图标后，为安装或更新前已打开的当前普通网页补充加载内容脚本 |
| `https://api.siliconflow.cn/*` | 只允许扩展后台访问硅基流动聊天补全接口 |
| `https://api.deepseek.com/*` | 只允许扩展后台访问 DeepSeek 聊天补全接口 |
| 普通网页内容脚本 | 读取用户主动选择的文字、显示悬浮窗及框选层 |

隐私边界：

- 两个 API Key 分开存入 `chrome.storage.local`，并限制为可信扩展上下文访问；内容脚本不会读取密钥。
- 本地扩展存储不是操作系统级加密保险箱。能访问本机 Chrome 用户配置的人仍可能取得密钥。
- 主动选择的文本只发送给本次实际选择的文本供应商；右键图片的可见区域或手动框选区域只发送给硅基流动。
- 扩展不会发送网页标题、网址、完整 HTML 或未裁剪的整页截图。
- 扩展不记录密钥、原文、图片 Base64、译文或请求历史，也不包含遥测和第三方脚本。
- API 调用可能产生费用，额度和计费以对应供应商账户为准。

## 9. 常见问题

### 选择文本后没有反应

请依次确认：

1. 工具栏弹窗中的“自动划词翻译”已打开；
2. 当前文本路由有可用的 API Key；
3. 弹窗显示“当前页面已启用划词翻译”；若提示不支持，请刷新当前普通网页；
4. 当前选择内容符合英语、日语或俄语的本地识别规则；
5. 安装或重新加载扩展后已经刷新当前网页和设置页；
6. 选择内容不在输入框、文本域、可编辑区域或内嵌 iframe 中。

如果设置页测试按钮显示扩展本地的“不支持的请求”，说明设置页或 service worker 仍是旧版本。请在 `chrome://extensions/` 重新加载扩展，再刷新设置页。1.1.1 版已修复标签页形式设置页被错误拒绝的问题。

### 图片翻译一直停在处理中

1.1.2 版修复了几个会导致图片翻译没有终态的问题：SSE 心跳或空帧不再无限延长等待；内部异常中止会转成可见错误；错误响应体按 10 秒和 64 KB 限制读取；前端还会在后台没有返回终态时自动停止请求。悬浮窗底部会显示实际上传图片的尺寸与体积，可据此判断卡在本地处理、上传还是模型首段输出。

升级后需要在 `chrome://extensions/` 重新加载扩展，并刷新已经打开的网页。若状态停在“正在向硅基流动发送图片”，请缩小框选区域后重试；若停在“模型已响应”，扩展会在首段译文超时后给出明确错误，可再切换到 `Qwen/Qwen3.5-4B` 测试。

### 提示 API Key 无效、无权限或速率受限

- `401`：通常表示 API Key 无效或已经失效；
- `403`：通常表示权限、实名状态或账户余额不满足供应商要求；
- `429`：通常表示触发供应商的速率限制。

打开设置页，对报错的供应商单独重新保存并测试连接。账户状态和模型权限需要在对应供应商控制台中确认。

### 图片截图失败

请确认当前标签页仍然处于激活状态，并重新操作。`chrome://` 内置页面、Chrome 网上应用店、浏览器设置页以及部分内置 PDF 查看器不允许普通扩展注入内容脚本或截图；请在普通网页中使用。

### 图片中的小字识别不准确

先放大页面，让目标文字清晰显示；然后只框选文字及少量上下文。过大的框选范围会降低小字在最终图片中的占比。

### 流式输出中断

网络中断、服务繁忙或长时间无返回都可能终止请求。重新选择文本或重新框选即可再次发起；扩展不会无限自动重试，避免重复计费。
