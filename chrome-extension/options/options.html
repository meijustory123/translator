隐私与费用提示

只有你主动选择的文字会发送给当前文本供应商；右键图片或手动框选的页面区域只会发送给硅基流动。 扩展不保存翻译历史，也不会发送网页标题、网址或完整 HTML。

API 调用可能产生费用，具体额度和计费规则以对应供应商账户为准。本地扩展存储不是系统级加密保险箱， 能访问本机 Chrome 配置的人仍可能取得其中的密钥。
